# Redis: Most Used Commands for MLOps & Data Science Engineers

---

## Overview

Redis has more than **200+ commands**, but in real production systems you only need a **small subset**.

For **MLOps, ML Engineers, and Data Scientists**, about **20–25 Redis commands cover ~90% of real-world use cases**.

These commands are commonly used in:

* ML API caching
* Feature stores
* Model metadata storage
* Rate limiting
* Job queues
* Real‑time pipelines
* Vector search systems

This guide focuses only on the **most practical Redis commands you actually need to remember**.

---

# 1. Basic Key Management Commands

These commands are used in **almost every Redis workflow**.

| Command | Description                                       | Example                    |
| ------- | ------------------------------------------------- | -------------------------- |
| SET     | Store a value                                     | `SET model:version "v1.2"` |
| GET     | Retrieve a value                                  | `GET model:version`        |
| DEL     | Delete a key                                      | `DEL model:version`        |
| EXISTS  | Check if a key exists                             | `EXISTS model:version`     |
| EXPIRE  | Set expiration time (TTL)                         | `EXPIRE cache:user:1 60`   |
| TTL     | Check remaining TTL                               | `TTL cache:user:1`         |
| KEYS    | Find keys by pattern                              | `KEYS user:*`              |
| SCAN    | Iterate keys safely (recommended instead of KEYS) | `SCAN 0 MATCH user:*`      |

### Example

```bash
SET model:latest "v2"
GET model:latest
EXPIRE model:latest 3600
TTL model:latest
```

# 2. String Commands (Most Frequently Used)

Redis **Strings** are the most widely used data type.

They are used for:

* Counters
* Caching
* Rate limiting
* API tracking
* Model versions

| Command | Description               | Example                            |
| ------- | ------------------------- | ---------------------------------- |
| SET     | Store value               | `SET user:1:name "John"`           |
| GET     | Retrieve value            | `GET user:1:name`                  |
| INCR    | Increment integer value   | `INCR api:requests`                |
| DECR    | Decrement integer value   | `DECR stock:item`                  |
| MSET    | Set multiple values       | `MSET a 1 b 2 c 3`                 |
| MGET    | Get multiple values       | `MGET a b c`                       |
| SETEX   | Set value with expiration | `SETEX cache:prediction 60 "0.93"` |

### Example

```bash
SET api_calls 10
INCR api_calls
GET api_calls
```

# 3. Hash Commands (Important for ML Systems)

Hashes are perfect for storing **structured objects**.

Example: storing **ML model metadata**.

```bash
HSET model:fraud version v1 accuracy 0.92 framework pytorch
```

| Command | Description          |
| ------- | -------------------- |
| HSET    | Set field in hash    |
| HGET    | Get field value      |
| HGETALL | Get all fields       |
| HDEL    | Delete field         |
| HKEYS   | Get all fields names |

### Example

```bash
HSET model:fraud version v1 accuracy 0.92
HGET model:fraud accuracy
HGETALL model:fraud
```

### Common Use Cases

* Model metadata
* Feature storage
* Experiment tracking

---

# 4. List Commands (Queues)

Lists are commonly used for **queues and pipelines**.

| Command | Description           |
| ------- | --------------------- |
| LPUSH   | Push element to left  |
| RPUSH   | Push element to right |
| LPOP    | Remove from left      |
| RPOP    | Remove from right     |
| LRANGE  | Get range of list     |

### Example (ML inference queue)

```bash
LPUSH inference_queue job1
LPUSH inference_queue job2
RPOP inference_queue
```

### Common Use Cases

* Background workers
* Task queues
* Data pipelines

---

# 5. Set Commands (Unique Elements)

Sets store **unique values only**.

| Command   | Description          |
| --------- | -------------------- |
| SADD      | Add member           |
| SMEMBERS  | Retrieve all members |
| SREM      | Remove member        |
| SISMEMBER | Check membership     |

### Example

```bash
SADD active_users user1 user2 user3
SMEMBERS active_users
```

### Common Use Cases

* Active user tracking
* Deduplication
* Unique identifiers

---

# 6. Sorted Set Commands (Ranking Systems)

Sorted sets store values **with scores**.

| Command   | Description                   |
| --------- | ----------------------------- |
| ZADD      | Add member with score         |
| ZRANGE    | Retrieve elements by rank     |
| ZREVRANGE | Retrieve highest scores first |
| ZREM      | Remove member                 |

### Example

```bash
ZADD leaderboard 100 user1
ZADD leaderboard 200 user2
ZRANGE leaderboard 0 -1 WITHSCORES
```

### Common Use Cases

* Leaderboards
* Recommendation engines
* Ranking systems

---

# 7. Pub/Sub Commands (Real‑Time Systems)

Redis Pub/Sub enables **real-time messaging**.

| Command   | Description             |
| --------- | ----------------------- |
| PUBLISH   | Send message to channel |
| SUBSCRIBE | Listen to a channel     |

### Example

```bash
SUBSCRIBE predictions
PUBLISH predictions "fraud_detected"
```

### Common Use Cases

* Real-time predictions
* Streaming pipelines
* Event notifications

---

# 8. Vector Search (Modern ML Use Case)

Redis supports **vector similarity search** using Redis modules.

Primary command used:

```
FT.SEARCH
```

### Example

```bash
FT.SEARCH idx "*=>[KNN 5 @vector $vec]" PARAMS 2 vec $BLOB
```

### Common Use Cases

* Retrieval-Augmented Generation (RAG)
* Semantic search
* Embedding similarity

---

# 9. Transaction Commands (Atomic Operations)

Transactions ensure **atomic execution of commands**.

| Command | Description           |
| ------- | --------------------- |
| MULTI   | Start transaction     |
| EXEC    | Execute transaction   |
| WATCH   | Watch key for changes |

### Example

```bash
MULTI
INCR counter
INCR api_calls
EXEC
```

---

# 10. Monitoring and Debug Commands

Useful for **monitoring Redis health and statistics**.

| Command | Description                         |
| ------- | ----------------------------------- |
| INFO    | Server statistics                   |
| PING    | Check connection                    |
| DBSIZE  | Count keys in database              |
| FLUSHDB | Delete all keys in current database |

### Example

```bash
PING
INFO
DBSIZE
```
